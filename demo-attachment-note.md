# Optional: Anhang (SharePoint / Copilot-Datei-Kontext)

Für Kunden mit **„Copilot über Dokumente“**: ST3GG zeigt, dass Angriffe auch **in Dateien** stecken ([ST3GG](https://github.com/elder-plinius/ST3GG)).

**Schulungs-sicher:**

1. Word-Dokx mit **verstecktem Text** (Schrift weiß oder Schriftgröße 1 pt): gleiche Canary-Anweisung.
2. Copilot: „Fasse dieses Dokument zusammen“ — nur im **Test-Team / Test-Site**.

Kein Bild-Stego-Pflichtteil — nur Erwähnung im Vortrag: „Vision + Agent = ST3GG-Vektor“.
